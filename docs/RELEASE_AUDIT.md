## 2. 출시 차단 문제

### Critical

#### C-01. 카카오 사용자 신원을 서버가 검증하지 않음

> **2026-10-07 로컬 수정 완료 / 운영 반영 대기:** iOS가 카카오 액세스 토큰을 전달하고 Worker가 카카오 `/v2/user/me`에서 검증한 뒤 자체 세션을 발급하도록 변경했다.

- **재현:** 임의의 `kakao_id`와 닉네임만 `/api/auth/kakao`로 보내도 새 계정이 201로 생성된다.
- **원인:** 서버가 카카오 액세스 토큰 또는 ID 토큰을 받거나 카카오 서버에 검증하지 않고 클라이언트가 보낸 식별자를 그대로 신뢰한다.
- **영향:** 다른 사람의 카카오 ID를 아는 공격자가 해당 사용자로 로그인할 수 있다.
- **근거:** `backend-cloudflare/src/index.ts:1385`, `Dog_kindergarden/Dog_kindergarden/AuthSession.swift:105`
- **조치:** 카카오 토큰을 서버로 보내고 서버가 카카오 사용자 API로 검증한 뒤 자체 세션 토큰을 발급해야 한다.

#### C-02. 사용자 데이터 API에 인증·객체별 권한 검사가 없음

> **2026-10-07 로컬 수정 완료 / 운영 반영 대기:** 보호 API에 Bearer 세션과 사용자·강아지·예약·채팅방 등 객체별 소유 관계 검사를 추가했다.

- **재현:** 로그인 정보 없이 사용자 번호만 바꿔 예약 목록을 조회할 수 있고, 다른 사용자의 `pet_id`로 예약도 만들 수 있다.
- **범위:** 프로필, 강아지, 찜, 예약, 채팅, 알림장, 알림, 리뷰 관련 API 전반.
- **영향:** 타인의 개인정보 조회·변경·삭제, 타인 강아지로 예약, 채팅 위조가 가능하다.
- **근거:** 전역 미들웨어는 CORS뿐이며(`backend-cloudflare/src/index.ts:171`), 사용자 번호를 URL·본문에서 직접 받는다. 예: 예약 생성 `:466`, 예약 조회 `:542`, 메시지 전송 `:856`, 강아지 삭제 `:1499`.
- **조치:** 모든 보호 API에 `Authorization: Bearer <token>` 검증을 넣고, 토큰의 사용자 ID와 DB 소유 관계를 서버에서 확인해야 한다.

#### C-03. 가게 소유권 등록과 사장님 작업을 위조할 수 있음

> **2026-10-08 로컬 수정 완료 / 운영 반영 대기:** 가게 등록은 승인 대기 요청만 만들고, 운영자 권한을 가진 개발자 실계정이 신청자 정보를 확인해 승인할 때만 `stores.owner_id`를 연결한다. 승인 전 접근, 일반 사용자의 운영자 요청함 접근, 타 사장님의 재등록을 자동 검사로 차단했다.

- **재현:** 보호자 계정의 사용자 번호로도 원하는 가게를 “내 가게”로 등록할 수 있다.
- **원인(수정 전):** `/api/stores/claim`이 본문의 `user_id`만 믿고 사장님 역할·사업자 확인·관리자 승인을 검사하지 않았다. 다른 사장님용 조회·확정 API도 인증된 호출자인지 확인하지 않았다.
- **영향:** 가게 탈취, 고객·강아지 개인정보 접근, 예약 확정·취소, 알림장 조작 가능.
- **근거:** `backend-cloudflare/src/index.ts:393`, `:421`, `:614`, `:638`, `:662`
- **조치 결과:** `store_owner_applications` 승인 대기열, 앱 내 운영자 전용 요청함, 승인·거절 API를 추가했다. 서버가 운영자 세션을 검사하고 승인 시에만 `owner_id`를 연결하며, 모든 사장님 API는 토큰 사용자와 `stores.owner_id`를 함께 검증한다. 실제 사업자 확인은 운영자가 별도 증빙과 신청 정보를 대조하는 수동 절차이며 자동 사업자 인증은 v2로 미룬다.

#### C-04. 관리자·내부 비용 발생 API가 공개됨

> **2026-10-07 로컬 수정 완료 / 운영 반영 대기:** `/api/admin/*`와 `/api/internal/*`를 Worker Secret 기반 `X-Internal-Key`로 잠갔다.

- **범위:** 가게 대량 업서트, 리뷰 요청 수동 실행, Workers AI 가격 OCR.
- **영향:** 운영 가게 데이터 변조, 원치 않는 메시지 발송, AI 비용 유발 및 남용 가능.
- **근거:** `backend-cloudflare/src/index.ts:320`, `:1640`, `:1647`
- **조치:** 공개 라우트에서 제거하거나 별도 관리자 인증·서명된 내부 키·Cloudflare 접근 정책을 적용한다.

### Major

#### M-01. 일반 업체에서도 예약·채팅이 열림

- 앱 상세화면은 업체가 실제 맡겨멍 파트너인지와 관계없이 하단 채팅·예약 버튼을 항상 보여준다.
- API도 `owner_id`가 없는 가게 예약을 허용해 응답할 사장님이 없는 예약이 생성된다.
- **근거:** `Dog_kindergarden/Dog_kindergarden/Views/StoreDetail/StoreDetailView.swift:49`, `:597`; `backend-cloudflare/src/index.ts:466`
- **조치:** 승인된 파트너 상태를 명시하고 파트너에만 예약·채팅·알림장·리뷰를 허용한다. 일반 업체는 정보 보기·전화·외부 지도만 제공한다.

#### M-02. 실제 가게와 무관한 고정 가격을 “총 결제 금액”으로 표시함

- 모든 업체에 시간권 5,000원, 종일권 35,000원, 숙박 50,000원을 적용한다.
- 픽업 선택 UI가 없는데도 모든 예약에 픽업비 10,000원을 자동 합산한다.
- 이 금액은 서버 예약 데이터에 저장되지 않고 완료 화면에만 표시된다.
- **근거:** `Dog_kindergarden/Dog_kindergarden/Views/Booking/BookingView.swift:22-28`, `:58-68`, `:418-435`
- **조치:** 결제 기능이 준비되기 전에는 금액을 제거하고 “예약 요청”으로만 안내하거나, 파트너가 등록·승인한 서비스와 가격만 사용한다.

#### M-03. 예약 상태 변경이 멱등하지 않고 존재하지 않는 예약도 성공 처리됨

- 같은 예약을 여러 번 확정하면 확정 안내 메시지가 매번 추가된다.
- 없는 예약 번호를 취소해도 200 `{ ok: true }`가 반환된다.
- 이미 취소된 예약의 확정 등 허용 가능한 이전 상태를 검사하지 않는다.
- **근거:** `backend-cloudflare/src/index.ts:570`, `:662`
- **조치:** `REQUEST → CONFIRMED/CANCELED` 조건부 업데이트, 변경 행 수 확인, 재호출 시 409 또는 기존 결과 반환, 자동 메시지 중복 방지 키를 추가한다.

#### M-04. 자동 테스트 타깃이 빌드되지 않으며 실제 테스트도 비어 있음

- 전체 `xcodebuild test`는 `Dog_kindergardenTests`가 `KakaoMapsSDK`, `KakaoSDKAuth`, `KakaoSDKCommon`, `KakaoSDKUser`를 찾지 못해 테스트 실행 전에 실패한다.
- Podfile에는 앱 타깃만 있고 테스트 타깃 의존성 상속이 없다.
- Unit test와 UI test는 Xcode 기본 예제만 존재한다.
- **근거:** `Dog_kindergarden/Podfile`, `Dog_kindergarden/Dog_kindergardenTests/Dog_kindergardenTests.swift:13`, `Dog_kindergarden/Dog_kindergardenUITests/Dog_kindergardenUITests.swift:26`
- **조치:** 테스트 타깃 의존성을 복구한 뒤 인증·권한, 예약 상태, 파트너 제한, 주요 UI 흐름을 자동화한다.

#### M-05. 회원 탈퇴와 개인정보 삭제 경로가 없음

> **2026-10-10 로컬 수정 완료 / 운영 반영 대기:** 앱 내 2단계 탈퇴 UI와 본인 전용 서버 탈퇴 API를 추가했다. 진행 예약이 있으면 탈퇴를 차단하고, 개인정보 삭제·운영 기록 익명화·가게 연결 해제·모든 세션 폐기·로컬 저장값 정리를 자동 검사했다.

- **수정 전:** 앱과 API 모두 계정 탈퇴, 개인정보 삭제 또는 예약·채팅 기록 익명화 흐름이 없었다.
- **조치 결과:** 탈퇴 영향 안내와 최종 확인, 본인 세션 검증, 진행 예약 차단, 개인정보별 삭제·익명화, 카카오 연결 해제와 로컬 저장값 정리를 구현했다. 구체적인 법정 보유기간과 백업 삭제 주기는 개인정보처리방침 공개 전에 확정해야 한다.

#### M-06. Sign in with Apple이 없음

- 현재 iOS 앱은 카카오 로그인만 제공한다.
- **조치:** 출시 심사 준비 항목으로 Apple 로그인과 카카오 계정 연결 정책을 추가한다.

#### M-07. Naver Client Secret이 앱 번들에 포함됨

- `Info.plist` 빌드 변수로 분리했지만, 빌드된 앱에서는 값을 추출할 수 있다.
- 지역·블로그 검색을 iOS가 직접 호출하면서 secret을 사용한다.
- **근거:** `Dog_kindergarden/Dog_kindergarden/Info.plist:32-35`, `Views/StoreDetail/NaverLocalService.swift:19`, `Views/Review/NaverBlogService.swift:26`
- **조치:** 네이버 호출을 Worker 프록시로 옮기고 서버 Secret으로 관리한다.

#### M-08. API 주소 설정이 서비스마다 달라 로컬 검증이 불완전함

- `APIClient`만 `API_BASE_URL` 설정을 따르고, 로그인·예약·강아지 기능은 운영 Worker 주소를 직접 사용한다.
- 로컬 서버로 테스트한다고 생각해도 일부 기능은 운영 서버를 호출할 수 있다.
- **근거:** `Dog_kindergarden/Dog_kindergarden/APIClient.swift:18`, `AuthSession.swift:18`, `Views/Booking/BookingView.swift:50`, `Views/DogProfile/DogProfileView.swift:36`
- **조치:** 환경별 단일 API 설정 객체로 통합하고 Debug/Release 설정을 분리한다.

#### M-09. 크롤링 데이터의 출처·사용 조건·갱신 이력이 운영 데이터에 없음

- 이미지·가격·영업시간을 앱에 노출하지만 각 값의 출처, 마지막 확인일, 이용 허용 범위를 사용자·운영자가 확인할 수 없다.
- **조치:** 운영 전 출처·권리 검토를 끝내고 `source`, `source_url`, `crawled_at` 또는 이에 준하는 필드를 추가한다. 권한이 불명확한 이미지는 숨긴다.

#### M-10. 일부 크롤링 이미지의 디코딩·메모리 경고가 발생함

- 시뮬레이터에서 `unsupported image format`, JFIF 처리 오류, PixelBuffer 생성 실패 로그가 확인됐다.
- **영향:** 일부 대표·상세 이미지가 비거나 큰 이미지에서 메모리 사용량이 증가할 수 있다.
- **조치:** 서버에서 허용 형식·용량·픽셀 크기를 검증하고 썸네일 변환·캐싱을 적용한다.

## 4. 확인한 정상 흐름

별도 로컬 D1에서 다음 흐름을 확인했다.

- 보호자·사장님 가입과 동일 카카오 ID 역할 충돌 차단
- 프로필 수정, 강아지 등록·목록
- 가게 상세정보·추가 이미지 저장 및 조회
- 가게 연결·사장님 가게 목록
- 찜 추가·목록·해제
- 채팅방 생성·메시지 송수신·사장님 문의함·안 읽음 수
- 예약 요청·사장님 대기 목록·확정·확정 목록·보호자 예약 목록
- 알림장 생성·조회·수정·삭제
- 이용 완료 예약의 리뷰 자격, 리뷰 작성, 같은 예약 중복 리뷰 차단, 리뷰 목록

이 성공 결과는 **인증·권한이 안전하다는 뜻이 아니다.** 현재는 요청자가 누구인지 확인하지 않기 때문에 정상 요청도, 위조 요청도 함께 성공한다.

## 5. 아직 완료하지 못한 실제 사용 점검

다음은 실제 기기와 실계정이 필요하거나, 위 Critical 문제를 먼저 고쳐야 의미 있게 검증할 수 있어 보류했다.

- 실제 카카오 로그인·로그아웃·계정 교차 로그인
- 실제 iPhone의 위치·캘린더·알림 권한 허용/거부/설정 복귀
- 느린 네트워크·오프라인·서버 오류에서 재시도와 오류 문구
- 앱 종료·재실행·백그라운드 복귀·알림 딥링크
- 보호자와 사장님 두 기기를 이용한 예약→확정→채팅→알림장→리뷰 전체 흐름
- VoiceOver, 글자 크기 확대, 작은 화면, 다크모드 등 접근성·레이아웃
