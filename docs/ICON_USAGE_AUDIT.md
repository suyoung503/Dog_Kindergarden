# 맡겨멍 화면별 아이콘 의미 점검

**점검일:** 2026-10-18  
**범위:** `Assets.xcassets`의 커스텀 아이콘, `EmojiIcon`·`EmojiTitle` 매핑, SwiftUI 호출 화면

## 1. 이미지와 이름 대조

| 에셋 | 실제 이미지 의미 | 사용하는 의미 | 판정 |
|---|---|---|---|
| `dog_b` | 흰색 비숑 프리제 형태 | 기본 강아지·사진 미등록 상태·순환 아바타 | 일치 |
| `dog_c` | 갈색 푸들 형태 | 보호자 역할·순환 강아지 아바타 | 일치 |
| `kindergarden` | 무지개가 있는 유치원 건물 | 애견 유치원 | 일치 |
| `emoji_hotel` | H 표지가 있는 호텔 건물 | 애견호텔 | 일치 |
| `icon_paw` | 발자국 | 반려견 공통·유형 혼합·미분류·사장님 공통 | 일치 |
| `emoji_calendar` | 달력과 시계 | 예약·날짜·받은 예약 | 일치 |
| `emoji_chat` | 대화 말풍선 | 채팅·문의 | 일치 |
| `emoji_note` | 메모지와 연필 | 알림장 | 일치 |
| `emoji_bone` | 강아지 뼈다귀 | 예약 서비스 선택 | 일치 |

`🏠`는 `kindergarden`, `🏨`는 `emoji_hotel`로 연결되어 있어 두 시설 이미지가 뒤바뀐 곳은 없었다. `📢`와 `⚠️`는 대응 커스텀 에셋이 없으므로 공지·오류 화면에서 시스템 이모지로 표시되는 것이 의도된 동작이다.

## 2. 화면 의미 대조와 수정

| 화면 | 기존 상태 | 판단과 반영 |
|---|---|---|
| 홈 호텔·유치원 필터와 지도 핀 | 유형에 따라 호텔/유치원 아이콘 사용 | 올바름, 공통 함수로 통일 |
| 최근 본 가게·찜·예약 내역 | 가게 유형 아이콘 사용 | 올바름, 공통 함수로 통일 |
| 보호자 채팅방 | 대화 상대 가게의 유형 아이콘 사용 | 올바름, 공통 함수로 통일 |
| 채팅방 아이콘 초기값 | 유치원 건물 고정 | 가게 유형을 아직 모르는 순간에는 공통 발자국을 사용하도록 변경 |
| 사장님 채팅방·알림장 | 상대 강아지 아바타 사용 | 올바름. 가게가 아닌 맡은 아이를 뜻함 |
| 로그인 역할 선택의 사장님 | 유치원 건물 고정 | 호텔 사장님도 선택하는 역할이므로 공통 발자국으로 변경 |
| 예약 화면 상단 요약 | 흰색 강아지 고정 | 가게명·날짜·서비스 요약이므로 선택한 가게 유형 아이콘으로 변경 |
| 가게 상세 제목 카드 | 흰색 강아지 고정 | 가게 자체를 나타내므로 호텔/유치원 유형 아이콘으로 변경 |
| 가게 유형 누락 데이터 | 호텔로 강제 표시 | 잘못된 호텔 표시를 막기 위해 지도 목록에서 제외하도록 변경 |
| 유형 혼합·미분류 데이터 | 화면마다 유치원 또는 호텔로 단정 가능 | `storeTypeEmoji`에서 공통 발자국으로 표시하도록 통일 |
| 예약 완료·찜 빈 화면·사진 미등록 | 일반 강아지 사용 | 특정 시설이나 견종을 주장하지 않는 장식·빈 상태이므로 유지 |
| 시작 화면의 유치원 건물+강아지 | 돌봄 시설을 설명하는 대표 일러스트 | 특정 데이터 행의 유형 표시가 아닌 서비스 소개 이미지이므로 유지 |

## 3. 코드 규칙

- 가게 유형 아이콘은 직접 삼항 연산자로 고르지 않고 `storeTypeEmoji(_:)`를 사용한다.
- `호텔`은 `🏨 → emoji_hotel`, `유치원`은 `🏠 → kindergarden`으로 표시한다.
- `유치원·호텔`처럼 두 유형이 함께 있거나 값이 없으면 어느 한쪽으로 단정하지 않고 `🐾 → icon_paw`를 사용한다.
- 보호자 시점 채팅은 가게 아이콘, 사장님 시점 채팅은 강아지 아바타를 사용한다.
- 실제 반려견 사진이 있으면 장식 아바타보다 사진을 우선한다.

이 규칙은 `Dog_kindergardenTests.iconSemanticMapping`에서 회귀 검사한다.

2026-10-18 iPhone 17 Pro 시뮬레이터에서 전체 단위 테스트 6/6 통과를 확인했다.

## 4. 별도 남은 출처 확인

이미지와 기능 의미는 일치하지만 `emoji_bone`과 `emoji_hotel`의 원본 제작자·개별 출처는 아직 확인되지 않았다. 의미 매핑 문제와 저작권 표기 문제는 별개이므로, 두 출처는 기존 출시 체크리스트에 따라 확인 후 마이페이지의 아이콘 출처 화면에 추가한다.
