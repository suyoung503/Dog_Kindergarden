# 맡겨멍 출시 로드맵 에이전트 실행표

**작성일:** 2026-10-09  
**기준 문서:** `docs/PLAN.md`

`PLAN.md`의 남은 항목을 서로 충돌하지 않는 구현 단위로 묶어 순차·병렬 진행한다. 각 구현 단위는 코드 검토와 검증을 통과한 뒤 하나의 독립 커밋으로 남기고, 같은 커밋의 `docs/PROGRESS.md`에 구현 방식·검증 결과·남은 수동 작업을 기록한다.

## 진행 규칙

1. 기능 코드와 해당 진행 기록을 한 커밋으로 묶는다.
2. 자동 검증이 불가능한 실제 기기·외부 계정·약관·사업자 확인은 완료로 표시하지 않는다.
3. 운영 배포가 필요한 변경은 로컬 구현 완료와 운영 반영 완료를 구분한다.
4. 동일 파일을 수정하는 작업은 병렬 실행하지 않는다.
5. Critical/P0 작업을 먼저 끝낸 뒤 P1 작업으로 이동한다.

## 자동으로 완료할 수 없는 항목

다음 항목은 코드만으로 완료 처리하지 않는다.

- Apple Developer Program 가입과 계약·결제
- 실제 iPhone에서 카카오/Apple/APNs/권한 동작 확인
- Cloudflare·Apple·Naver 콘솔의 운영 Secret 및 제한 설정
- 네이버 데이터 운영 사용 가능 여부에 대한 권리자·약관 확인
- 개인정보처리방침의 최종 운영자 정보와 법률 검토
- TestFlight 참여자와 실제 가게 파일럿 확보
- App Store Connect 등록과 심사 제출

에이전트는 위 항목에 필요한 코드·문서·체크리스트까지 준비하고, 사람이 수행한 증거가 확인된 뒤에만 `PLAN.md` 체크 상태를 변경한다.
