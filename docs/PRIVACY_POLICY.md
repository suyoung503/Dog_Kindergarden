# 맡겨멍 개인정보처리방침

> **공개 URL:** <https://matgyeomung-api.dog-kindergarden.workers.dev/privacy>
>
> 실제 소스 코드와 운영 서버의 삭제·익명화 및 보유기간 정리 작업을 기준으로 관리합니다.

맡겨멍(이하 “서비스”)은 이용자의 개인정보를 중요하게 생각하며, 관련 법령을 준수하기 위해 다음과 같이 개인정보처리방침을 공개합니다.

## 1. 수집하는 개인정보

서비스는 기능 제공에 필요한 범위에서 다음 정보를 처리합니다.

| 구분 | 수집·처리 항목 | 필수 여부 및 수집 방법 |
|---|---|---|
| 카카오 로그인 및 계정 | 카카오 사용자 식별자, 닉네임, 이메일(카카오에서 제공되고 이용자가 동의한 경우), 맡겨멍 내부 사용자 ID, 보호자·사장님 역할 | 계정 생성과 로그인에 필요하며 카카오 로그인을 통해 수집 |
| 프로필 | 닉네임, 전화번호, 주소, 선택 이메일 | 닉네임은 계정 표시에 사용하며, 연락처·주소·선택 이메일은 이용자가 프로필에서 직접 입력·수정 |
| 반려견 정보 | 이름, 견종, 나이, 몸무게, 성별, 사회성, 알레르기, 특이사항, 이용자가 선택한 프로필 사진 1장 | 이용자가 반려견 프로필을 등록할 때 수집 |
| 예약 정보 | 이용 가게, 이용일·시간, 서비스 종류, 예약 상태, 요청사항 | 이용자가 예약을 신청하거나 가게가 예약을 처리할 때 생성 |
| 서비스 이용 콘텐츠 | 가게 문의 및 채팅 내용, 알림장 내용과 사진(건당 최대 3장), 리뷰의 별점·선택 태그·본문 | 이용자 또는 승인된 가게 사장님이 직접 작성·선택 |
| 서비스 이용 기록 | 찜한 가게, 채팅 읽음 상태, 사장님 가게 등록 신청·승인 상태와 처리 시각 | 해당 기능을 사용할 때 생성 |
| 인증·보안 정보 | 맡겨멍 세션 토큰의 SHA-256 해시, 세션 생성·만료 시각, 지정 운영자의 카카오 서비스 사용자 ID를 SHA-256 처리한 해시 | 로그인 시 자동 생성. 앱에는 원문 세션 토큰을 Keychain에 저장하며, 운영자 식별 해시는 접근 통제용 Worker Secret으로 계정 DB와 분리해 보관 |

현재 앱은 다음 정보를 서비스 서버로 수집하지 않습니다.

- 기기의 현재 위치 또는 이동 경로
- 기기의 캘린더 내용: 이용자가 선택한 예약 신청 일정을 기기 캘린더에 추가·삭제할 때만 Apple EventKit을 사용하며, 캘린더 내용을 맡겨멍 서버로 전송하지 않습니다.
- 동영상과 카메라 직접 촬영물: 현재 직접 촬영 기능은 연결되어 있지 않습니다. 강아지 프로필 사진과 알림장 사진은 시스템 사진 선택기에서 이용자가 명시적으로 고른 항목만 저장합니다.
- 광고 식별자(IDFA), 광고 데이터 또는 앱 간 추적 정보
- 충돌 로그·성능 진단 정보를 수집하는 별도 분석 SDK 데이터

## 2. 개인정보 이용 목적

서비스는 개인정보를 다음 목적으로만 이용합니다.

1. 이용자 식별, 로그인 상태 유지 및 계정 보안
2. 보호자·사장님 역할 구분과 권한 관리
3. 사진을 포함한 반려견 프로필, 가게 탐색, 찜, 예약 기능 제공
4. 보호자와 승인된 가게 사장님 사이의 채팅 및 알림장 제공
5. 실제 이용 완료 여부를 확인한 리뷰 작성 기능 제공
6. 사장님 가게 등록 신청의 운영자 확인·승인·거절
7. 서비스 오류 대응, 부정 이용 방지 및 분쟁 대응

서비스는 개인정보를 맞춤형 광고, 제3자 광고 또는 이용자 추적 목적으로 사용하지 않습니다.

## 3. 개인정보의 보유 및 이용기간

개인정보는 수집·이용 목적을 달성한 후 지체 없이 파기하는 것을 원칙으로 합니다. 다만 관계 법령에 따라 보존할 의무가 있거나 서비스 운영상 보존이 필요한 경우에는 해당 기간 동안 분리하여 보관할 수 있습니다.

| 정보 | 현재 확인된 처리 기준 |
|---|---|
| 로그인 세션 | 발급 후 30일. 로그아웃·탈퇴 시 즉시 폐기하며, 만료된 세션 해시는 만료 후 30일 이내 삭제합니다. |
| 계정·프로필·반려견·찜 | 회원 탈퇴 시 카카오 식별자와 프로필을 익명화하고 반려견·찜을 서비스 DB에서 즉시 삭제합니다. |

| 리뷰 | 계정 유지 중 서비스 제공을 위해 보관하고, 탈퇴 시 작성자·본문을 익명화합니다. 개인을 알아볼 수 없는 리뷰 통계는 개인정보가 아닌 형태로 보관할 수 있습니다. |
| 소비자 불만·분쟁 처리 기록 | 관련 법령이 적용되는 경우 처리 완료일부터 3년간 보관합니다. |

취소 예약의 7일 보관 정책은 운영 배포 전에 법정 보존 의무와 적용 범위를 검토해야 합니다.

앱의 마이페이지에서 회원 탈퇴를 시작할 수 있습니다. 진행 중인 보호자 예약 또는 소유 가게 예약이 있으면 완료하거나 취소한 뒤 탈퇴할 수 있으며, 탈퇴가 완료되면 같은 계정의 모든 로그인 세션이 폐기됩니다.

## 4. 개인정보의 제3자 제공

서비스는 이용자의 개인정보를 원칙적으로 제3자에게 판매하거나 제공하지 않습니다. 다만 다음 경우에는 예외로 합니다.

1. 이용자가 사전에 동의한 경우
2. 법령에 특별한 규정이 있거나 법적 의무를 이행해야 하는 경우
3. 이용자가 신청한 예약·채팅·알림장 기능을 제공하기 위해 필요한 범위에서, 관리자 승인을 거쳐 해당 가게와 연결된 사장님에게 정보를 보여주는 경우

예약을 처리하는 승인된 사장님에게는 예약 수행에 필요한 보호자 닉네임·연락처·주소, 반려견 정보, 예약 요청사항 등이 제공될 수 있습니다. 다른 가게의 사장님은 해당 정보에 접근할 수 없도록 계정과 가게의 소유 관계를 검사합니다.

## 6. 개인정보 파기 절차 및 방법

보유기간이 끝나거나 처리 목적이 달성된 개인정보는 복구하기 어려운 방법으로 삭제합니다.

- 전자적 파일과 데이터베이스 정보: 복구가 어렵도록 삭제
- 앱 내부 정보: 로그아웃·탈퇴 처리 시 세션과 계정 관련 로컬 저장값 삭제
- 운영자가 생성한 복구용 백업: 생성일부터 30일 이내 안전하게 삭제

## 7. 이용자의 권리와 행사 방법

이용자는 자신의 개인정보에 대해 열람, 정정, 삭제, 처리정지를 요청할 수 있습니다. 프로필 정보는 앱에서 직접 수정할 수 있으며, 그 밖의 요청은 제10조의 연락처로 접수합니다. 본인 확인이 필요한 경우 최소한의 정보를 추가로 요청할 수 있습니다.

회원 탈퇴는 앱의 `마이페이지 → 회원 탈퇴`에서 요청할 수 있습니다. 탈퇴 전에 삭제·익명화 범위를 안내하고 최종 확인을 받으며, 진행 중 예약이 있으면 안전한 예약 처리를 위해 탈퇴를 제한합니다. 탈퇴 후 재가입하면 새 계정으로 처리되어 이전 반려견·찜·예약 정보가 자동 승계되지 않습니다. 다만 서비스 운영자로 지정된 카카오 계정은 별도 보관된 식별 해시가 일치할 때 운영자 권한만 새 계정에 복구됩니다.

## 8. 개인정보 보호를 위한 조치

서비스는 다음과 같은 보호 조치를 적용합니다.

- 카카오 액세스 토큰을 서버에서 검증한 뒤 맡겨멍 세션을 발급
- 서버에는 세션 토큰 원문이 아닌 SHA-256 해시만 저장
- 지정 운영자의 카카오 서비스 사용자 ID도 원문 대신 SHA-256 해시만 Worker Secret으로 분리 보관
- 앱의 세션 토큰은 iOS Keychain에 저장
- 보호 API에서 로그인 사용자와 요청 대상의 소유 관계 및 역할 검사
- 사장님은 운영자 승인을 받아 연결된 자기 가게의 예약·채팅·알림장에만 접근 가능
- 반려견 프로필 사진과 알림장 사진은 공개 URL이 아닌 비공개 R2에 저장. 반려견 프로필 사진은 해당 계정이 관리하며, 예약 요청·확정 상태에서 해당 승인 가게 사장님에게만 예약별 인증 API로 읽기 제공. 알림장 사진은 해당 예약의 보호자와 승인된 가게 사장님만 인증 API로 열람
- 통신 구간 HTTPS 사용
