# 맡겨멍 개인정보처리방침

맡겨멍(이하 “서비스”)은 이용자의 개인정보를 중요하게 생각하며, 관련 법령을 준수하기 위해 다음과 같이 개인정보처리방침을 공개합니다.

## 1. 수집하는 개인정보

서비스는 기능 제공에 필요한 범위에서 다음 정보를 처리합니다.

| 구분 | 수집·처리 항목 | 필수 여부 및 수집 방법 |
|---|---|---|
| 카카오 로그인 및 계정 | 카카오 사용자 식별자, 닉네임, 이메일(카카오에서 제공되고 이용자가 동의한 경우), 맡겨멍 내부 사용자 ID, 보호자·사장님 역할 | 계정 생성과 로그인에 필요하며 카카오 로그인을 통해 수집 |
| 프로필 | 닉네임, 전화번호, 주소 | 닉네임은 계정 표시에 사용하며, 전화번호와 주소는 이용자가 프로필에서 직접 입력·수정 |
| 반려견 정보 | 이름, 견종, 나이, 몸무게, 성별, 사회성, 알레르기, 특이사항 | 이용자가 반려견 프로필을 등록할 때 수집 |
| 예약 정보 | 이용 가게, 이용일·시간, 서비스 종류, 예약 상태, 요청사항 | 이용자가 예약을 신청하거나 가게가 예약을 처리할 때 생성 |
| 서비스 이용 콘텐츠 | 가게 문의 및 채팅 내용, 알림장 내용, 리뷰의 별점·선택 태그·본문 | 이용자 또는 승인된 가게 사장님이 직접 작성 |
| 서비스 이용 기록 | 찜한 가게, 채팅 읽음 상태, 사장님 가게 등록 신청·승인 상태와 처리 시각 | 해당 기능을 사용할 때 생성 |
| 인증·보안 정보 | 맡겨멍 세션 토큰의 SHA-256 해시, 세션 생성·만료 시각 | 로그인 시 자동 생성. 앱에는 원문 세션 토큰을 Keychain에 저장 |

현재 앱은 다음 정보를 서비스 서버로 수집하지 않습니다.

- 기기의 현재 위치 또는 이동 경로
- 기기의 캘린더 내용: 예약 확정 일정을 기기 캘린더에 추가·삭제할 때만 Apple EventKit을 사용하며, 캘린더 내용을 맡겨멍 서버로 전송하지 않습니다.
- 이용자의 사진·동영상: 현재 강아지 사진 버튼과 알림장 사진 스키마는 실제 업로드 기능으로 연결되어 있지 않습니다.
- 광고 식별자(IDFA), 광고 데이터 또는 앱 간 추적 정보
- 충돌 로그·성능 진단 정보를 수집하는 별도 분석 SDK 데이터

## 2. 개인정보 이용 목적

서비스는 개인정보를 다음 목적으로만 이용합니다.

1. 이용자 식별, 로그인 상태 유지 및 계정 보안
2. 보호자·사장님 역할 구분과 권한 관리
3. 반려견 프로필, 가게 탐색, 찜, 예약 기능 제공
4. 보호자와 승인된 가게 사장님 사이의 채팅 및 알림장 제공
5. 실제 이용 완료 여부를 확인한 리뷰 작성 기능 제공
6. 사장님 가게 등록 신청의 운영자 확인·승인·거절
7. 서비스 오류 대응, 부정 이용 방지 및 분쟁 대응

서비스는 개인정보를 맞춤형 광고, 제3자 광고 또는 이용자 추적 목적으로 사용하지 않습니다.

## 4. 개인정보의 제3자 제공

서비스는 이용자의 개인정보를 원칙적으로 제3자에게 판매하거나 제공하지 않습니다. 다만 다음 경우에는 예외로 합니다.

1. 이용자가 사전에 동의한 경우
2. 법령에 특별한 규정이 있거나 법적 의무를 이행해야 하는 경우
3. 이용자가 신청한 예약·채팅·알림장 기능을 제공하기 위해 필요한 범위에서, 관리자 승인을 거쳐 해당 가게와 연결된 사장님에게 정보를 보여주는 경우

예약을 처리하는 승인된 사장님에게는 예약 수행에 필요한 보호자 닉네임·연락처·주소, 반려견 정보, 예약 요청사항 등이 제공될 수 있습니다. 다른 가게의 사장님은 해당 정보에 접근할 수 없도록 계정과 가게의 소유 관계를 검사합니다.

서비스는 현재 다음 외부 사업자의 기술을 사용합니다. 정식 출시 전 계약 관계와 국외 처리 여부를 법률·운영 기준에 맞게 최종 확인하고, 필요한 고지나 동의를 추가합니다.

| 사업자·서비스 | 이용 목적 | 처리되는 정보 또는 동작 |
|---|---|---|
| Cloudflare, Inc. (Workers, D1) | API 운영과 데이터베이스 호스팅 | 서비스 계정 및 제1조의 서버 저장 데이터 처리 |
| Kakao Corp. (Kakao Login) | 카카오 계정 로그인 | 카카오 사용자 식별자, 닉네임, 동의한 경우 이메일, OAuth 인증 정보 |
| Kakao Corp. (Kakao Maps SDK·Local API) | 지도와 가게 위치·주소 표시 | 가게명과 가게 좌표 등 가게 탐색 정보. SDK 자체 개인정보 선언은 앱 배포본의 Privacy Report에서 함께 확인 |
| NAVER Corp. (검색 API) | 가게 상세정보 및 블로그 검색 결과 표시 | 가게명과 가게 위치 등 검색 질의. 이용자의 계정 프로필은 전달하지 않음 |
| Apple Inc. (EventKit·알림) | 예약 일정의 기기 캘린더 저장 및 기기 알림 | 이용자가 허용한 기기 안에서 처리하며 맡겨멍 서버가 캘린더 내용을 수집하지 않음 |

## 7. 이용자의 권리와 행사 방법

이용자는 자신의 개인정보에 대해 열람, 정정, 삭제, 처리정지를 요청할 수 있습니다. 프로필 정보는 앱에서 직접 수정할 수 있으며, 그 밖의 요청은 제10조의 연락처로 접수합니다. 본인 확인이 필요한 경우 최소한의 정보를 추가로 요청할 수 있습니다.

현재 회원 탈퇴 기능과 서버 데이터 삭제·익명화 절차는 출시 전 구현 과제로 남아 있습니다. 기능이 완성되기 전에는 탈퇴가 가능한 것처럼 안내하지 않습니다.

## 8. 개인정보 보호를 위한 조치

서비스는 다음과 같은 보호 조치를 적용합니다.

- 카카오 액세스 토큰을 서버에서 검증한 뒤 맡겨멍 세션을 발급
- 서버에는 세션 토큰 원문이 아닌 SHA-256 해시만 저장
- 앱의 세션 토큰은 iOS Keychain에 저장
- 보호 API에서 로그인 사용자와 요청 대상의 소유 관계 및 역할 검사
- 사장님은 운영자 승인을 받아 연결된 자기 가게의 예약·채팅·알림장에만 접근 가능
- 통신 구간 HTTPS 사용

## 9. 만 14세 미만 아동의 개인정보

서비스는 만 14세 미만 아동을 대상으로 설계되지 않았으며, 법정대리인의 동의 없이 만 14세 미만 아동의 개인정보를 수집하지 않습니다. 관련 정보가 수집된 사실을 알게 된 경우 제10조의 연락처로 알려주시기 바랍니다.
