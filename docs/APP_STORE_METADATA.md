## 2. 설명

```text
우리 아이를 안심하고 맡길 곳, 맡겨멍에서 찾아보세요.

맡겨멍은 서울 지역의 강아지 유치원과 애견호텔을 지도에서 탐색하고, 파트너 가게에 예약을 요청할 수 있는 반려견 돌봄 서비스입니다.

주요 기능

• 지도에서 가게 찾기
서울 지역의 애견 유치원과 호텔을 지도에서 살펴보고, CCTV·픽업·대형견 이용 가능 여부 등 필요한 조건을 확인할 수 있습니다.

• 가게 정보와 사진 확인
주소, 전화번호, 영업시간, 가격 안내와 가게 사진을 한곳에서 확인할 수 있습니다. 수집된 정보는 참고용이므로 이용 전 가게에 최신 내용을 확인해 주세요.

• 반려견 프로필 관리
이름, 견종, 나이, 몸무게, 성격과 특이사항을 등록해 예약할 때 활용할 수 있습니다.

• 예약 요청과 일정 관리
예약 기능이 활성화된 파트너 가게에 날짜와 서비스를 선택해 예약을 요청하고 진행 상태를 확인할 수 있습니다. 앱 안에서는 결제를 진행하지 않습니다.

• 보호자와 가게 채팅
예약과 관련된 요청사항을 가게와 1:1 채팅으로 주고받을 수 있습니다.

• 우리 아이 알림장
가게가 작성한 식사, 산책, 놀이 등 돌봄 기록을 예약별 알림장에서 확인할 수 있습니다.

• 실제 이용자 리뷰
이용 완료 기록이 있는 보호자만 리뷰를 작성할 수 있으며, CCTV·픽업·대형견 이용 가능 여부 같은 정보를 함께 남길 수 있습니다.

• 찜한 가게
관심 있는 가게를 저장하고 마이페이지에서 다시 확인할 수 있습니다.

현재 가게 탐색 범위는 서울입니다. 일반 업체는 기본 정보만 제공하며, 예약·채팅·알림장은 관리자 승인을 받은 파트너 가게에서만 지원합니다.
```

## 3. 연령 등급 설문 입력 기준

최종 등급은 App Store Connect 설문 결과로 확정한다. 현재 기능을 기준으로 다음과 같이 답한다.

| 설문 항목 | 답변 기준 | 근거 |
|---|---|---|
| Made for Kids | 아니요 | 아동 대상 앱이 아님 |
| 자녀 보호 기능 | 없음 | 보호자 통제 기능 없음 |
| 연령 확인 | 없음 | 별도 연령 인증 없음 |
| 사용자 생성 콘텐츠 | 있음 | 이용 완료 보호자의 리뷰 |
| 메시지·채팅 | 있음 | 보호자와 승인된 가게의 1:1 채팅 |
| 소셜 미디어 | 없음 | 공개 피드·팔로우 기능 없음 |
| 무제한 웹 접근 | 없음 | 앱 내 범용 브라우저 없음 |
| 광고 | 없음 | 광고 SDK·광고 노출 없음 |
| 의료·건강 정보 | 없음 | 의료 진단·치료 정보 제공 안 함 |
| 폭력·선정성·약물·도박 | 모두 없음 | 해당 콘텐츠와 기능 없음 |

사용자 생성 콘텐츠와 메시지 기능을 반드시 설문에 표시하고, Apple이 산정한 등급을 임의로 낮추지 않는다.

## 4. App Review 심사 노트 초안

```text
맡겨멍은 서울 지역의 강아지 유치원·호텔을 탐색하고 실제 반려견 돌봄 서비스를 예약 요청하는 앱입니다.

1. 앱에서 판매하는 디지털 콘텐츠나 인앱결제는 없습니다. 예약은 오프라인 반려견 돌봄 서비스에 대한 요청이며, 표시 가격은 참고 정보입니다.
2. 예약·채팅·알림장 기능은 관리자가 실제 운영자를 확인하고 승인한 파트너 가게에서만 활성화됩니다. 일반 업체에는 기본 정보만 표시됩니다.
3. 사용자는 예약 완료 이력이 있는 가게에만 리뷰를 작성할 수 있습니다.
4. 캘린더 권한은 예약 완료 화면에서 사용자가 ‘캘린더에 추가’를 누를 때만 요청합니다. 권한을 거부해도 예약 기능을 사용할 수 있습니다.
5. 가게 위치 확인 시 Kakao 지도 페이지, 후기 확인 시 Naver 블로그 결과처럼 특정 외부 페이지가 시스템 브라우저에서 열릴 수 있습니다. 앱 내부에 범용 웹 브라우저는 없습니다.
6. 회원 탈퇴는 마이페이지에서 직접 진행할 수 있습니다. 진행 중인 예약이 있으면 완료 또는 취소 후 탈퇴할 수 있습니다.

검토 순서와 계정 정보는 아래 ‘제출 전 확정 필요’ 항목을 완료한 뒤 이 노트 하단에 추가합니다.
```

## 5. 제출 전 확정 필요

- [ ] 보호자 심사용 카카오 계정과 로그인 방법
- [ ] 승인된 파트너 가게가 연결된 사장님 심사용 카카오 계정과 로그인 방법
